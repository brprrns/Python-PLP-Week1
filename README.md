# Week 1 - Python Assignments

This repository contains my Week 1 assignments for Phase 1 of the Python learning program.

The assignments focus on the basic concepts of Python and are organized into separate files for each question.

## Topics Covered

* Data Types, Variables, Operators and Type Conversion
* Lists, Tuples, Sets and Dictionaries
* Control Flow and Loops
* Functions and Arguments
* String Operations and File Handling
* Exception Handling


## Requirements

* Python 3.x
* Any Python IDE or code editor such as VS Code, PyCharm, or IDLE

No external libraries are required.

## Learning Goals

Through these assignments, I practiced:

* Working with Python variables and data types
* Type conversion
* Using operators
* Working with different collection types
* Using conditional statements and loops
* Creating and using functions
* Working with strings and files
* Handling errors using exceptions
